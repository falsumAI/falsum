# What Was Built — Falsum v1.1.0

## The Application

Falsum.exe — .NET 8 WPF desktop application. Native Windows software, not a website.

## 53 Module Cards

45 PowerShell modules (legacy backend) + 5 native C# services + ProtectAll + AI Chat + Coherence.

## 5 Native C# Services (New)

1. **EnergyFraudService** — Detects power anomalies. Miners, spyware, telemetry caught by energy.
2. **HiddenFileService** — Exposes hidden files and Alternate Data Streams. Makes everything readable.
3. **BrowserDownloadService** — Tracks all browser downloads. SHA-256 hashed, risk-scored.
4. **NetworkCommandService** — Full network control via CMD. Plain language. CMD's capabilities are the floor.
5. **InfrastructureDetectorService** — Detects Windows PCs running cell phone infrastructure.

## Browser Bubble

The extension swallows the browser. Every navigation, download, upload, fingerprint attempt gated by the desktop app. Fail-closed. Nothing leaves without consent.

## Accessibility

All 6 windows screen-reader accessible. Keyboard navigation. A blind person can use this.

## Android App

VPN-based tracker blocking. Permission auditor. Stalkerware scanner. Infrastructure detector. Screen reader support.

## Competitive Position

vs Shawn Ryan's Glacier App: 40x on problem count (2,000 vs ~50). Free vs paid. Open vs closed. Cross-platform vs iOS-only. Local AI vs none.
