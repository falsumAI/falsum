# Falsum User Guide

## What is Falsum?

Free security software for your Windows computer. No subscriptions. No cloud. No one watching you.

## Getting Started

1. Run Falsum.exe
2. Click **"Protect Me"** — that's it. Falsum checks everything and fixes what it can.
3. Read what it found. Every result is in plain language.

## The Main Screen

53 cards. Each one does one thing. Click any card to run it.

- **Protect Me** — One click. Runs everything safe in the right order.
- **AI Chat** — Talk to your local AI. It lives on your computer. Correct it with "wrong, [correction]" and it learns.
- **Browser Bubble** — The extension that swallows your browser. Nothing leaves without your permission.

## Native Services (No Scripts)

These are built into the app as real code:

- **Energy Fraud Detector** — Finds programs burning your electricity. Crypto miners, spyware, hidden telemetry.
- **Hidden File Hunter** — Finds files Windows is hiding from you. Makes them visible.
- **Download Tracker** — Shows every file your browsers downloaded. Tells you which ones are dangerous.
- **Network Commander** — Control your entire network in plain language. No jargon.
- **Infrastructure Detector** — Finds out if your PC is running phone company software it shouldn't.

## The Browser Extension

Install it from the Settings. Once installed:

- Every website you visit is checked before it loads
- Every download is scanned before it saves
- Every tracker is blocked and logged
- If the desktop app isn't running, dangerous stuff is blocked automatically

## For Screen Reader Users

Every button, every card, every status message works with screen readers. Press Tab to move. Press Enter to activate. Status updates are announced automatically.

## Your Data

Nothing leaves your computer. Ever. No account. No telemetry. No cloud. The evidence vault is on your hard drive, encrypted, hash-chained.

## Getting Help

Every card explains what it does in plain language. If something is wrong, the app tells you what to do about it.
